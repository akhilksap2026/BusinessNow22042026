## PHASE 2 — GAP ANALYSIS (Read-Only, No Changes)

⚠️ DO NOT modify any file in this phase. Read and observe only.

Using the inventory from Phase 1, check every item below.
Reference EXACT file paths and line numbers for each gap found.
Do not suggest fixes yet — only document what is missing.

### PSA-Specific Checks

TIMESHEET MODULE:
- [ ] Can an Employee approve their own timesheet? (Critical)
- [ ] Can a PM approve timesheets for projects they don't own? (High)
- [ ] Is the 24-hour/day cap enforced at the API layer, not just UI? (High)
- [ ] Can submitted/approved/invoiced time be edited by anyone 
      other than PMO Manager or Admin? (Critical)
- [ ] Are the unsubmit and force-edit endpoints protected with 
      PM + Admin guard only? (Critical)

PROJECT MODULE:
- [ ] Can an Employee create or assign projects? (Critical)
- [ ] Can a PM edit projects they don't own? (High)
- [ ] Can a Designated PM access projects they are not 
      designated on? (High)
- [ ] Is baselining restricted to PM, PMO Manager, Admin? (Medium)
- [ ] Can a Customer portal user access any project other 
      than their own? (Critical)

BILLING & INVOICING:
- [ ] Are rate card create/edit endpoints restricted to 
      PMO Manager + Admin? (Critical)
- [ ] Can any non-admin role view costRate? (High)
- [ ] Are invoice generation/approval endpoints restricted? (High)
- [ ] Is PMO category config locked to PMO Manager + Admin? (Medium)

RESOURCE MANAGEMENT:
- [ ] Can an Employee view other employees' allocation or 
      rate data? (High)
- [ ] Can a PM modify resource allocations on projects 
      they don't own? (High)
- [ ] Is hard/soft allocation type change restricted to 
      PM-level and above? (Medium)

USER MANAGEMENT:
- [ ] Is role assignment/promotion restricted to Admin only? (Critical)
- [ ] Can any user demote or deactivate another user? (Critical)
- [ ] Is org hierarchy management restricted to Admin? (High)
- [ ] Is there an audit log for every role change? (High)

DASHBOARD & REPORTS:
- [ ] Are financial dashboards (margin, cost rates, revenue) 
      restricted to PMO Manager + Admin? (High)
- [ ] Can an Employee access company-wide aggregate reports? (High)
- [ ] Are Customer portal users seeing only their own 
      project deliverables? (Critical)

GENERAL CHECKS:
- [ ] Frontend-only guards — any route hidden in UI but 
      unprotected at API? (Critical)
- [ ] IDOR risks — can User A access User B's timesheets or 
      project data by changing an ID? (Critical)
- [ ] Are roles re-validated from DB on sensitive operations 
      or blindly trusted from token? (High)
- [ ] Hardcoded role strings scattered across route files 
      instead of a central constant? (Medium)
