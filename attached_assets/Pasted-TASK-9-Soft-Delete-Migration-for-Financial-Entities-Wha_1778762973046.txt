Step 9.4: Update DELETE route handlers
For EACH of these routes, change from hard delete to soft delete:
Before:
typescriptrouter.delete('/allocations/:id', requirePM, async (req, res) => {
  await db.delete(allocations).where(eq(allocations.id, id));
  // ...
});
After:
typescriptrouter.delete('/allocations/:id', requirePM, async (req, res) => {
  await db
    .update(allocations)
    .set({ deletedAt: new Date() })
    .where(eq(allocations.id, id));
  // ...
});
Step 9.5: Update all SELECT queries
Add isNull(table.deletedAt) filter to all queries on these tables:
typescript// Before:
const items = await db.query.allocations.findMany({
  where: eq(allocations.projectId, projectId)

// After:
const items = await db.query.allocations.findMany({
  where: and(
    eq(allocations.projectId, projectId),
    isNull(allocations.deletedAt)
  )
