BusinessNow PSA — Enterprise Audit Report
Executive Summary
The platform demonstrates strong functional breadth (10+ modules, RBAC scaffolding, AI assistance, guard helpers) but carries significant production-readiness gaps across four dimensions: (1) auth model is dev-only — header-trust auth would be trivially spoofable in prod; (2) referential integrity is largely absent — most foreign keys lack .references() + onDelete clauses, putting the database one accidental delete away from cascading orphans; (3) denormalized aggregates drift silently — tracked_hours, project budgets, and revenue figures are recomputed in-memory but never reconciled against source-of-truth tables; (4) workflow guards are surface-level — several critical state machines (CR conversion, opportunity-to-project, billing-from-timesheet) lack idempotency checks, allowing duplicate side-effects on retry. Test suite (65 tests) covers happy-path business logic but no infra/concurrency/auth-bypass coverage. Recommend a 2-sprint hardening pass before any external customer onboarding.

Recommended Improvements (concrete)
Architecture / Security

Replace header-trust auth with Replit Auth or session cookies + signed JWTs; keep header model only when NODE_ENV=development.
Add helmet, express-rate-limit (e.g., 100 req/min per IP), and a global Express error handler.
Mandate .strict() on every safeParse() for write endpoints.
Add a Drizzle migration that: (a) adds .references() + onDelete: "cascade" (or "set null") on every existing FK; (b) adds indexes on the hot-path columns listed in H6.
Data Integrity
5. Either drop projects.tracked_hours (compute via aggregate) or add a post-insert/update trigger function in timeEntries.ts wrapped in db.transaction().

Wrap billingSchedules.ts:90-105 invoice + schedule update in a transaction.
Add idempotency keys to POST /opportunities/:id/convert-to-project and POST /timesheets/:id/invoice.
Workflow Hardening
8. Add not_started to ALLOWED_TRANSITIONS; write a test that exercises every documented transition.

Block manual budget Adjustment entries when budgetLocked=true unless an approved CR is referenced.
Move closedProjectGuard to also check deletedAt.
UX / Ease of Operation
11. Sticky table headers + actionable status badges (1-day change, huge usability win).

cmdk command palette for power users.
"Copy last week" button on timesheet grid.
Replace Archive confirm dialogs with Undo toasts (already have useUndoableMutation).
Group project-detail tabs into 2 levels.
Testing
16. Add concurrency tests: simultaneous timesheet approval, dual conversion of the same opportunity, simultaneous CR approve.

Add auth bypass tests: spoofed header, mismatched x-user-id / x-user-role, role escalation attempts.
Add integration tests for the full lifecycle: opportunity → project → tasks → time → invoice → revenue recognition.
