## CATEGORY 1: TIME ENTRY (14 Requirements)

| Req | Requirement |
|-----|-------------|
| T1  | Role-based time entry — only KSAP consultants (not customers) can enter time, scoped to their assigned Projects and Tasks |
| T2  | Free-form notes at the time entry level (optional) |
| T3  | Consultant sees only their own assigned projects and tasks |
| T4  | Weekly grid view — days of the week × projects, multiple entries per task per day, with category selection and comments |
| T5  | Time Entry Category selection from a PMO-defined list |
| T6  | Billable / Not Billable checkbox per time entry |
| T7  | Time Entry Category carries a default Billable flag that can be overridden by the consultant |
| T8  | Time entry can be updated and saved throughout the week; submitted only once |
| T9  | After submission, only PM and Admin can edit or unsubmit time |
| T10 | Only PM, designated PM, PMO Manager, and Admin can approve weekly time |
| T11 | Approved + Invoiced time is locked; only PMO Manager or Admin can unlock |
| T12 | Daily time entered by a consultant cannot exceed 24 hours |
| T13 | PMO Manager and Admin define and maintain Time Entry Categories used across all projects |
| T14 | All employees across departments can log time |
